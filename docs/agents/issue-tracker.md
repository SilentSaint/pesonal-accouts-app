# Issue Tracker

Issues for this project live in GitHub Issues for `SilentSaint/pesonal-accouts-app`.

- **Type**: `github`
- **CLI**: `gh issue`
- **Repo**: `SilentSaint/pesonal-accouts-app`
- **PRs as request surface**: `false`

## Usage Rules for Agents

- Create issues using `gh issue create`.
- Read issues using `gh issue view` or `gh issue list`.
- Update issue status using `gh issue edit` or comments.
